# 按钮分布与交互动画 · 开发对照

> 对应画布：https://ardot.tencent.com/file/740202263295204
> 基准版本：0.3.3 (303)　画板宽度 390dp（工程直接按 dp 用，360 / 412 机型同样成立）
> **本次只改布局与动效，不改美术风格**：颜色、玻璃填充、圆角、字体全部沿用现有 `Theme.kt` 里的 token，下面所有「改」都指位置 / 尺寸 / 分组 / 层级 / 动效。

---

## 0. 三条分布原则

1. **主操作一屏只有一个**。实心高对比（现有 `#EDEDED` 底 / `#17171A` 字）只给最高频那个动作。
2. **次操作并列但不抢戏**。玻璃填充（白 8%~15%）+ 0.5dp 描边；同一条视觉带最多 3 个，第 4 个起收进「更多」。
3. **低频与破坏性动作移出主视觉带**。重新打点、返回列表、清空、删除，一律进「更多」或页面底部独立区。

**统一约束**：视觉尺寸可以小于 44，但**热区必须 ≥ 44×44**。圆形图标按钮 = 44 容器 + 34 视觉；文字按钮高 36 时外围各补 4。相邻热区间距 ≥ 8。

### 1.3 提前量交互

- **入口（2026-10-25 改）**：⋮ 菜单第一项「翻页提前量　+0ms」→ 弹窗。弹窗里上半是 `−` `值` `＋`，
  下半是一个 ms 输入框（点中间数值 = 把当前值同步进输入框，不关弹窗）。
- 值胶囊 / 输入框 → 直接输入 ms，范围 −500~500。
- `−/＋` 单击 ±100ms；**长按 100ms 连发**（首次延迟 300ms）；松手吸附到 **50ms 网格**。
- 写入仍走 `SettingsStore.pageTurnOffsetMs`（已有 coerce −500..500，不动）。

网格修正的算术依据：`(360 − 36 + 12) ÷ (168 + 12) = 1`。改成 `Fixed(2)` 后 360dp 屏每列 162dp，不再出现整屏宽的巨幅正方形。

### 3.3 项目详情页：封面 → 全屏看图

原来是「点封面直接拉起换图选择器」。改成两步：

1. 点封面 → **全屏看图**（黑底铺满、`ContentScale.Fit`、点任意处 / 返回键关闭，不接捏合缩放）。
2. 全屏页底部两个操作：**另存图片**（实心 `#EDEDED`，存进系统相册 `Pictures/WhereverPlay`）、
   **更换图片**（玻璃，拉起 Photo Picker）。

理由：封面在详情页只有 96dp，看不出是否选错图；而「换图」是低频动作，不该是点击封面的第一结果。
详情页本身仍然只有一个主操作（播放），这次没有新增任何底部按钮。

编辑页同理：伴奏音频与 PDF 谱面两个文件条目右侧，除了「更换」还有一个「另存」（SAF 另存为，零权限）。


### 3.2 播放列表行（PlaylistEditScreen 的 EntryRow）

一行原有 3 个文字按钮 `↑ ↓ ✕`。改为：

- 长按整行进入拖动排序（拖动把手是**视觉提示**，不是独立按钮，44 容器内 6 点 SVG）
- 右侧只留一个删除图标（44×44）

行内可点区域从 5 个降到 3 个，排序从「点两次」变成「拖一次」。

行首 46dp 方块：原来是 `≡` 占位符，现在显示**列表里第一首「可用」项目的封面**
（`CoverView` + `rememberCoverBitmap(140)`，取不到就落占位色）。扫一眼就能认出是哪个列表，
不需要读名字。

## 4. 交互动画参数表

| # | 动效 | 触发 | 时长 / 曲线 | 位移 / 缩放 |
|---|---|---|---|---|
| 01 | 跟手翻页 | 横向拖动谱面区 | 拖动 1:1 无缓动；回弹 **160ms**；翻页 **220ms** | 页偏移 = 手指位移；松手阈值：屏宽 12%，或 > 5% 且速度 > 0.55 px/ms |
| 02 | 控制栏显隐 | 单击谱面区 | **180ms**，`(0.4, 0, 0.2, 1)` | 透明度 0↔1 + 上移 4dp；淡出只做透明度 |
| 03 | 按钮按压 | 所有可点元素 | 按下 **90ms** ease-out；回弹 **140ms** | scale 1.0→0.96→1.0；圆形按钮另加 12% 白环 0.7→1.1（120ms） |
| 04 | 底栏 Tab 切换 | 点 tab / 横滑页面 | 点 tab：**320ms** spring(380, 0.82) 滚页；横滑：**零延迟跟手**（选中块 = `currentPage + offsetFraction`，只重排不重组） | 选中块在胶囊内滑动，跟手时停在两格之间，松手吸附；文字色 180ms |
| 05 | 打点添加 / 选中 | 添加 / 点圆点 | 添加 **220ms** spring(380, 0.7)；色环 **240ms**；选中 **180ms** | 圆点 0.4→1.0；色环 1.0→1.8 淡出；选中半径 +5 |
| 06 | 曲间遮罩 | 一首播完 | **200ms** 淡入 | 0→1；倒计时数字每 1000ms 脉冲 1.0→1.06→1.0（各 120ms） |

### Compose 对照

```kotlin
// 曲线
CubicBezierEasing(0.2f, 0f, 0f, 1f)   // 翻页
CubicBezierEasing(0.4f, 0f, 0.2f, 1f) // 控制栏
spring(dampingRatio = 0.82f, stiffness = 380f) // tab / 圆点

// 按压反馈：interactionSource 收 isPressed，不要用 pointerInput 自己判
val pressed by interaction.collectIsPressedAsState()
Modifier.graphicsLayer {
    val s = if (pressed) 0.96f else 1f
    scaleX = s; scaleY = s
}
```

### 注意（现有工程已踩过的坑，不要复退）

- 翻页那一段的手势 key 必须用 `Unit` + `rememberUpdatedState`，高频 state 不能当 `pointerInput` 的 key。
- 翻页完成后把 `dragOffset` 直接归零，**不要**再接第二段动画，否则会看到「翻两下」。
- 控制栏显隐只改控制带，**不要**改谱面区尺寸，否则翻页时谱面跳动。
- 时间轴拖动期间必须冻结视窗（`frozenStart`），1px 恒等固定时长。

## 5. 我建议但**没有画**进画布的两项

1. **底栏加图标**：现在是纯文字（项目 / 播放列表 / 设置）。`icon 18 + label 10` 的胶囊底栏辨识度会更高，但这属于美术风格变更，按你的要求先不动。
2. ~~**提前量做成滑块**：`−/＋` 适合微调，但演出前要一次调 200ms 就要点两下。滑块 + 数值并列会更好，同样属于控件形态变化，先留作选项。~~
   **已落地（2026-10-25）**，但落在**设置页**而不是播放页：播放页的提前量弹窗仍是 `− 值 ＋`（演出中要微调、要能一眼看出当前值），
   设置页换成滑块（−500…+500，50ms 一档）+ 数值，因为那里是「一次性调好」的场景。
   设置页的翻页动画也从「切换」文字按钮改成三段胶囊（无 / 淡入淡出 / 滑动）。
