| 改了什么 | 触及文件 | 状态 | 备注 |
|---|---|---|---|
| **① 星标收藏不再算「最近修改」** | `ui/AppRoot.kt` | 🟨 | `stampUpdate` 的对比拷贝里加 `isFavorite = prev.isFavorite`，和 `manualTurn`、三个时间字段一起排除。单点星（首页卡片/详情页）与长按多选「批量收藏」都走这个出口，一处改全覆盖。**口径变化**：`功能想法与修复清单.md` 里「收藏也算修改」的说法作废，改名/作者/标签/封面/音频/谱面/打点/BPM 仍然算 |
| **② 打点页播放中点击进度条不再停止播放** | `ui/MarkingScreen.kt`、`ui/MarkingTimeline.kt` | 🟨 | `onScrub` 增加 `fromTap` 参数区分「单击跳转 / 拖动擦洗」。单击：`seekTo` 后继续播；拖动擦洗仍然暂停（80ms 一次连续 seek，边播边拖声音会碎）。新增 `seekGuardUntil` 忽略窗口（300ms）：MediaPlayer 的 `currentPosition` 在 seek 完成前还是旧值，不挡一下播放循环会立刻把光标拉回去，表现为「点了没反应」 |
| **③ 打点页微调行常驻，预览窗不再突然缩小** | `ui/MarkingScreen.kt` | 🟨 | 微调行由「选中才组合」改成**恒高 40dp 常驻**：未选中时显示原来底部那句操作提示（底部那行 Text 已删），选中时变回四个微调胶囊。预览区 `weight(1f)` 不再被临时挤掉 40dp |
| **④ 打点页时间轴改为分段翻页（取消光标居中跟随）** | `ui/MarkingTimeline.kt` | 🟨 | `followStart = 光标 − 半屏` 删除，换成 `segmentStart = floor(光标 / visible) × visible`（末段贴右边界）。播放时视窗**一动不动**、光标从左走到右；走到最右端视窗整段硬切到下一段、光标回到最左端。`followRef` 改名 `segmentRef`；**拖动期间冻结视窗的逻辑原样保留**（踩坑表里那条正反馈修复不能动），松手后视窗对齐到光标所在段。缩放变化 → 段宽变化 → 视窗重新对段（光标会跳一下，已告知用户） |
| **⑤ 播放页控制栏不再压缩谱面，改半透明黑叠加** | `ui/PlaybackScreen.kt` | 🟨 | 删掉 `topInset` / `bottomInset` 两个 `animateDpAsState`（56dp / 100dp），谱面区恒定整屏；顶栏、底部控制区背景 `#0B0B0E` → `#CC0B0B0E`（80% 黑，谱面能透出来）。顶/底栏各加一个空 `detectTapGestures` 消费点击 —— 谱面现在在栏的下层且占满整屏，不消费的话点栏上空白处会穿透下去把控制栏又切换没了。顺带删掉不再用的 `animateDpAsState` import 与 `controlBarHeight` 常量 |

## 2026-10-26（会话 B，版本 **0.2.2 / 202**）

**主题**：排序闪烁修复 + 新建落点 + 手动翻谱重做（用户第 1–3 项，分批交付的第一批）

### 代码改动

| 改了什么 | 触及文件 | 状态 | 备注 |
|---|---|---|---|
| 排序切升序/降序时**不再闪一下** | `ui/ProjectListScreen.kt` | 🟨 | 根因：回顶部是「等两帧再 `scrollToItem(0,0)`」，那两帧里内容已重排、位置还在旧索引，先渲染出列表中间再被拉回顶部。改成 `requestScrollToItem(0,0)`，与改排序在同一次快照里生效。删掉 `scrollToTopAfterRelayout` 及配套的 `scope` / `withFrameNanos` / `launch` 导入 |
| 新建项目完成后**不再自动进打点页** | `ui/AppRoot.kt` | 🟨 | `onCreated` 从 `route = Route.Mark(id)` 改成 `route = null`（回首页列表）+ 一句 toast |
| **手动翻谱重做**：作用域三态 + 开关搬到播放页左下角 + 设置页全局默认 | `domain/Model.kt`、`domain/Playlist.kt`、`data/JsonProjectStore.kt`、`data/JsonPlaylistStore.kt`、`data/WplayIO.kt`、`ui/AppRoot.kt`、`ui/PlaybackScreen.kt`、`ui/SettingsScreen.kt` | 🟨 | 见下 |

**手动翻谱（0.2.2 版设计）**

- `Project.manualTurn: Boolean?`、`Playlist.manualTurn: Boolean?` —— **三态**：`null` = 没单独设置过 → 回退设置页的「默认手动翻谱」；`true/false` = 在播放页左下角点过，以它为准。
- 播放列表播放时改的是**整个列表**（列表里换歌不重置，`remember(manualScopeKey)`）；单曲播放时改的是**这个项目**。`Route.Play` 新增 `playlist` 字段承载这个作用域。
- 开关在控制行**左下角**（胶囊 28 视觉 / 44 热区），居中播放键不受影响；`⋮` 里上一版加的那一项已删除。
- 三态会跟着 `.wplay` / `.wplist` 一起走（只对「设过」的写键，缺键即 null，老文件不受影响）。
- `AppRoot.stampUpdate` 把 `manualTurn` 和三个时间字段一起排除在「内容修改」之外 —— 否则点一下开关，项目就窜到「最近修改」第一位。
- 设置页新增「默认手动翻谱」开关（`SettingsStore.manualTurn`，键名沿用）。
