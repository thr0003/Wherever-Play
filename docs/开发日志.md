## 2026-10-26（会话 B，版本 **0.2.2 / 202**）

**主题**：排序闪烁修复 + 新建落点 + 手动翻谱重做（用户第 1–3 项，分批交付的第一批）

### 代码改动

| 改了什么 | 触及文件 | 状态 | 备注 |
|---|---|---|---|
| 排序切升序/降序时**不再闪一下** | `ui/ProjectListScreen.kt` | 🟨 | 根因：回顶部是「等两帧再 `scrollToItem(0,0)`」，那两帧里内容已重排、位置还在旧索引，先渲染出列表中间再被拉回顶部。改成 `requestScrollToItem(0,0)`，与改排序在同一次快照里生效。删掉 `scrollToTopAfterRelayout` 及配套的 `scope` / `withFrameNanos` / `launch` 导入 |
| 新建项目完成后**不再自动进打点页** | `ui/AppRoot.kt` | 🟨 | `onCreated` 从 `route = Route.Mark(id)` 改成 `route = null`（回首页列表）+ 一句 toast |
| **手动翻谱重做**：作用域三态 + 开关搬到播放页左下角 + 设置页全局默认 | `domain/Model.kt`、`domain/Playlist.kt`、`data/JsonProjectStore.kt`、`data/JsonPlaylistStore.kt`、`data/WplayIO.kt`、`ui/AppRoot.kt`、`ui/PlaybackScreen.kt`、`ui/SettingsScreen.kt` | 🟨 | 见下 |

**手动翻谱（0.2.2 版设计）**

- `Project.manualTurn: Boolean?`、`Playlist.manualTurn: Boolean?` —— **三态**：`null` = 没单独设置过 → 回退设置页的「默认手动翻谱」；`true/false` = 在播放页左下角点过，以它为准。
- 播放列表播放时改的是**整个列表**（列表里换歌不重置，`remember(manualScopeKey)`）；单曲播放时改的是**这个项目**。`Route.Play` 新增 `playlist` 字段承载这个作用域。
- 开关在控制行**左下角**（胶囊 28 视觉 / 44 热区），居中播放键不受影响；`⋮` 里上一版加的那一项已删除。
- 三态会跟着 `.wplay` / `.wplist` 一起走（只对「设过」的写键，缺键即 null，老文件不受影响）。
- `AppRoot.stampUpdate` 把 `manualTurn` 和三个时间字段一起排除在「内容修改」之外 —— 否则点一下开关，项目就窜到「最近修改」第一位。
- 设置页新增「默认手动翻谱」开关（`SettingsStore.manualTurn`，键名沿用）。

### 版本

`versionCode 201 → 202`、`versionName 0.2.1 → 0.2.2`（`app/build.gradle.kts`）。

### 遗留

- 本批三项全部**待用户验证**（我只到编译通过）。
- 用户第 4–6 项（无音频项目 / 12 分钟默认时长 / 移除音频与打点夹紧）**尚未开工**，等这一批验完再做。
