# 功能想法清单

> 最后更新：2026-10-25（0.2.1）
> 状态：✅ 已完成　🟡 部分完成　⬜ 未开始　❌ 已舍弃

| # | 想法 | 状态 | 说明 |
|---|---|---|---|
| 1 | 星标收藏 | ✅ | 项目星标 + 首页「收藏」筛选 |
| 2 | 项目搜索 | ✅ | 按曲名 / 作者匹配 |
| 3 | 排序方式 | ✅ | 两项：**最近修改 / 名称**（「创建时间」已删，2026-10-26）。最近修改 = 项目内容最后被改动的时刻（`updatedAt`）：改名/作者/标签/收藏/换封面/换音频/换谱面/改打点/改 BPM 都算；**点进去看、播放、导出不算**。搜索词、收藏/标签筛选、排序和升降序在进出详情/播放后**保留**（状态提升到 AppRoot，修掉了「回来跳回最近修改」的 bug）。`updatedAt` 是设备本地属性，**不进 `.wplay`**；导入的排最前 |
| 4 | 长按多选（项目） | ✅ | 批量删除、批量收藏、批量导出 |
| 5 | 自定义名称 / 作者 / 封面 | ✅ | 详情页改名称作者、点封面换图，封面自动裁正方形 |
| 6 | 播放列表 / 串烧 | ✅ | 创建、上下移排序、衔接方式、失效项占位 |
| 7 | 更换歌曲 / 更换谱面 | ✅ | 已拆到「编辑」页。**0.2.1 起更换不再清空打点**，原有打点保留（换谱面页数变少时只丢掉越界的那几条） |
| 8 | 播放列表长按多选 | ✅ | 批量删除、批量导出 |
| 9 | 播放列表拖动排序 | ✅ | 长按整行拖动。**已改为边拖边换位**（旧版松手按位移反推目标行，会跳错位置） |
| 10 | 乐器标签 | ✅ | 内置人声/电吉他/木吉他/贝斯/鼓/键盘/尤克里里/其它，可自建（总数上限 20），**一个项目只能选一个**；卡片封面左下角显示。**新建项目页也能选**（之前只有详情页能改） |
| 11 | 风格标签 | ❌ | 用户明确舍弃 |
| 12 | 首页筛选 | ✅ | 右上角漏斗，按乐器标签筛，可与搜索、收藏叠加。按作者筛未做（搜索已经能按作者匹配） |
| 13 | 中英文切换 | ⬜ | 需先把全部文案抽成资源文件，功能冻结后再做 |
| 14 | `.wplay` 导入导出 | ✅ | 格式（ZIP + manifest）、导出（单个另存为 / 多选选目录）、导入（＋ → 导入）均已完成。**Intent 打开已舍弃**（2026-10-25 用户明确），只从 App 内导入 |
| 15 | 后台播放 + 通知栏 | ❌ | 用户明确舍弃（2026-10-25）。播放页 `keepScreenOn` 默认开，演出时不熄屏，原目标场景已被覆盖；且 Android 8+ 后台播必须前台服务 + 通知，代价是重写播放器层 + 动播放页状态机，风险最高收益最低 |
| 16 | 页内纵向裁切 | ⬜ | TAB 谱一页多个 system 时，按段翻页而不整页翻 |
| 17 | 多色主题 | ⬜ | 预设几套配色 + 可自定义强调色，作用到按钮、圆点、进度条、玻璃高光 |
| 18 | 字体大小 / 背景图 / 浅色主题 | ⬜ | 外观设置 |
| 19 | 收藏夹分组、云同步 | ⬜ | 远期 |
| 20 | 项目信息增加 **BPM**、**调** | ⬜ | 详情页元信息（和名称/作者/乐器标签同一块）。BPM 存数值，用于展示 + 将来节拍器/速度参考；「调」待明确含义——**调性**（C 大调 / a 小调）还是**调弦**（标准 / Drop D / 半音降）？定下来再定是用预设列表还是自由文本。两者都要能进 `.wplay` manifest 且老数据缺字段时按 null 兼容 |
| 21 | **项目长按多选 → 添加到播放列表** | ⬜ | 现在多选只有「收藏 / 导出 / 删除」。要能批量把选中的项目追加进某个已有播放列表（或现建一个）。要点：同一项目在列表里已存在时去重提示、追加后保持列表原有顺序、加完给一句 toast |
| 22 | **播放时谱面尽量占满全屏** | ⬜ | 现在谱面按宽度 `min(400dp, 屏幕宽度)` 渲染再居中，上下留白很大。改成按**可用高度**反推需要多宽（取两者较小值），让单页/双页模式都尽量顶满。注意 `PdfPageRenderer` 的缓存按像素算，变宽后一页字节数会涨，48MB 预算要复核 |
| 23 | **手动模式（打点不生效，全人工翻谱）** | ⬜ | 运行时的开关：打开后忽略 `marks` 的自动翻页，只响应手动翻/滑；配合打点页不受影响（打点页照旧按时间轴）。要点：切换瞬间不能跳页、进度条上打点竖线是否还画待定、开关放播放页「更多」里还是设置页待定 |
| 24 | **播放时双指缩放，双击回正** | ⬜ | 谱面手势：双指捏合缩放 + 双指拖动平移，**单指双击复位**到 1:1。难点是和现有**单指左右滑翻页**共存（`detectHorizontalDragGestures` 与 `detectTransformGestures` 抢手势），以及缩放后翻页动画、打点跳页的坐标换算 |
